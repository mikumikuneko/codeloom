# 决策：思考内容用中性字段存，投影层统一不回传

## 是什么问题

模型会返回"思考过程"（reasoning）。存不存？存了之后要不要在下一次请求里回传给模型？

## 定了什么

存，字段名用中性的 `reasoning`（不用任何一家 provider 的私有字段名）；**投影层统一不回传**；回不回传由 provider 的适配层决定。

## 还考虑过什么，为什么没选

- **在请求里关掉思考**（有 provider 提供这种开关）：那是针对一家的开关，放进领域层就等于让领域模型学会一家的方言。
- **维护一张"哪家要回传"的表**：表会越来越长，而且每一行都要跟着上游 API 走；判断依据是别人的协议细节，不该住在我们的领域层。
- **照"带签名的思考块"那套做信封**（有些协议要求把思考原样带回来、并且带签名）：我们走的是 OpenAI 兼容线，**没有签名这回事** —— 学它的形状是为一个不存在的需求写代码。
- **全部回传 / 全部丢弃**：两家要求相反（一家明确不要回传，另一家的思考块必须带回来），一刀切必然错一半。

## 代价与换来的

- 一个已知的小坑：同一次回复被拆成两条消息时，思考可能被带上两次 —— 真实协议认不认，留给联调确认。
- 换来的是：领域层里没有一家 provider 的私有形状；换一家只动适配层。这条和"模型能力表不按一家 provider 的形状设计"是同一条纪律。
